# FECBox Android

Independent Android client for [FECBox](https://github.com/ZengLineng/sing-box-fec), based on SagerNet/sing-box-for-android at `ae93152f21457723af77d144f28c1f7be7362aec`.

The application ID is `dev.zenglineng.fecbox`, so it can coexist with the official client. Signed APKs are built and released by the parent FECBox repository using its pinned libbox AAR and a persistent signing key. This is not an official SagerNet distribution. Import a FECBox Android configuration before connecting.

Source namespace and libbox APIs are preserved for compatibility; app branding, update source and signing identity belong to this fork. The parent repository pins this commit in `clients/android`.
